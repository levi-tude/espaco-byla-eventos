# Política de segurança

## Como reportar uma vulnerabilidade

Não abra issue pública. Use o reporte privado do GitHub:
**Security → Report a vulnerability** neste repositório.

Inclua, se possível: o que você encontrou, passos para reproduzir e o impacto.
Responderemos assim que possível e avisaremos quando a correção for publicada.

## Escopo

- Site publicado: https://espaco-byla-eventos.vercel.app
- Código deste repositório.

Fora do escopo: ataques de negação de serviço, engenharia social e testes que
façam compras reais, alterem dados de outras pessoas ou acessem contas de terceiros.

## Versões suportadas

Apenas a versão em produção (branch `main`).
